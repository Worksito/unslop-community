# Unslop community

Animated React components that don't look AI-generated, shared by independent developers.
Each component lives in one file, ships with a demo and a short preview video, and is
published on Unslop with its author's name.

- **Use a component:** copy `src/library/<name>.tsx` into your project (React, no dependency unless its entry says otherwise).
- **Propose yours:** read [CONTRIBUTING.md](CONTRIBUTING.md) (in French for now), then open a pull request.
- **Try them locally:** `npm install`, then `npm run dev` and open the bench page.

Every pull request is checked automatically (format, security, preview video), then reviewed by hand before publication.

Components are released under the [MIT licence](LICENSE).
